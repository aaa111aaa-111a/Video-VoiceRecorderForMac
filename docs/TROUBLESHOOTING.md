# 音が入らないときの切り分け

「録画はできたのに音が入っていない」は、原因が 4 層に分かれます。上から順に潰してください。
OptiRecord の**レベルメーターは録画前でも動く**（モニタリングモード）ので、
本番の会議で失敗する前に必ずここで確認してください。

---

## 0. まずレベルメーターを見る

メニューバーから OptiRecord を開き、録画対象を選ぶとメーターが動き始めます。

| システム音声 | マイク | 見立て |
|---|---|---|
| 振れる | 振れる | 正常。そのまま録画してよい |
| 振れない | 振れる | → **1章**（画面収録権限 / 出力デバイス / 対象アプリ） |
| 振れる | 振れない | → **2章**（マイク権限 / 入力デバイス） |
| どちらも振れない | | → **1章の 1-1** から。権限が根本原因のことが多い |

---

## 1. システム音声（相手の声）が入らない

### 1-1. 画面収録の権限
システム音声は「画面収録」権限に紐づいています。マイク権限ではありません。

- システム設定 > プライバシーとセキュリティ > **画面収録** に OptiRecord があり、オンになっているか
- 一覧にすら出てこない場合は、一度アプリを終了して再起動する
- 自分でビルドした（ad-hoc 署名の）場合、**リビルドのたびに許可がリセットされる**ことがあります。
  その場合は一覧から OptiRecord を削除（−ボタン）してから再度追加してください

### 1-2. 音の出力先が「Mac のスピーカー」以外になっている
ScreenCaptureKit が拾うのは **Mac がアプリから受け取った音** なので、
出力先が AirPods でも外部スピーカーでも録れます。ただし例外があります。

- **すでに BlackHole / Loopback / Soundflower などの仮想デバイスに出力している**場合、
  そちらへ経路が変わっていると OptiRecord 側が拾えないことがあります。
  出力先を一度「MacBook のスピーカー」や実機のヘッドフォンに戻して確認してください
- 会議アプリ側の「スピーカー」設定も同様に確認する

### 1-3. 録画対象をアプリ単位で選んでいる
「アプリケーション」を対象に選ぶと、**そのアプリの音だけ**が録音されます。

- **Google Meet はブラウザのタブ**です。対象は Zoom や Teams ではなく
  **Chrome / Safari / Edge** を選んでください
- Meet を PWA としてインストールしている場合は、アプリ一覧にその PWA が出ます
- 迷ったら「画面全体」を選ぶ。全アプリの音が入るので取りこぼしません

### 1-4. 会議アプリ側でミュートされている
当たり前ですが、相手がミュートしていれば当然無音です。
OptiRecord のメーターと、会議アプリの参加者一覧の発話インジケータを見比べてください。

---

## 2. マイク（自分の声）が入らない

### 2-1. マイクの権限
システム設定 > プライバシーとセキュリティ > **マイク** に OptiRecord があり、オンになっているか。

### 2-2. 入力デバイスが会議アプリに占有されている
macOS では通常、複数アプリが同じマイクを同時に使えます。ただし:

- **Bluetooth ヘッドセットのマイク**を使うと、macOS は音質の低い HFP/HSP プロファイルへ
  切り替わり、**再生音質も電話並みに落ちます**。会議録画の音質を優先するなら、
  マイクは Mac 内蔵マイクか有線マイクにして、再生だけ Bluetooth にするのがおすすめです
- OptiRecord の設定 > 音声 > マイクデバイス で明示的に選べます

### 2-3. 録画中にデバイスを抜き差しした
録画中に USB マイクを抜くと、その時点以降が無音になります。
OptiRecord はデバイス切断を検知してログに残しますが、録画自体は継続します（映像とシステム音声は残ります）。

---

## 3. 録れているが音がずれる / 後半でずれていく

システム音声とマイクは別のクロックで動いているため、素朴に足し合わせると
時間とともにずれます。OptiRecord は絶対フレーム位置で書き込むことでこれを防いでいますが、
それでも気になる場合:

- macOS 15 以降なら、マイクも ScreenCaptureKit 経由で取得されるためズレはさらに小さくなります
- サンプルレートを揃える: 「Audio MIDI 設定」でマイクの入力を **48000 Hz** に設定する
- 設定 > 音声 > 「別ファイルにも書き出す」を有効にすると、マイクとシステム音声の
  m4a が個別に残るので、編集ソフト側で微調整できます

## 4. 音は入っているが小さい / 割れる

- 設定 > 音声 のゲインスライダーで各ソースを調整（既定 1.0 倍）
- メーターが赤（クリップ）になるなら下げる。緑の上端付近が最も良い
- 相手の声が小さくマイクが大きい場合は、**システム音声を上げるのではなくマイクを下げる**方が
  ノイズが乗りません

---

## それでも解決しない場合

コンソールにログが出ています。ターミナルで:

```sh
log stream --predicate 'subsystem == "app.optirecord.OptiRecord"' --info
```

を実行しながら録画を開始すると、どの層で止まっているか分かります。
`capture` / `audio` / `writer` のカテゴリを見てください。
